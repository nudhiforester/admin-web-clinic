# Login Page
1. Desain : `docs\login.png`
2. Terdiri dari 2 kolom kiri dan kanan.
3. Kolom kiri menampilkan informasi faskes sesuai `data\json\config.json`.
4. Kolom kanan menampilkan form login, sistem melakukan validasi akses sesuai `data\json\user.json`.
5. Tombol Login dengan google tidak perlu di fungsikan.

# Dashboard
1. Desain : `docs\dashboard.png`
2. Terdapat menu kiri dalam bentuk icon.
3. Terdapat header yang menampilkan informasi profil pengguna, icon mode gelap, icon notifikasi dan nama faskes.
4. Tampilan grapik menggunakan pustaka apexchart yang sudah ada pada project ini.
